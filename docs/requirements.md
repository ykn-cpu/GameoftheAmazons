# 作业要求

> 来源：计算概论 A 实验题（亚马逊棋），2025 年秋

## 基本要求

1. 有菜单选择（新开始、存盘、读盘、结束）
2. 用字符实现画棋盘和棋子
3. 一方选手是人类，另一方是计算机 AI
4. 程序输入落子和放障碍的坐标，在棋盘上显示变化
5. 允许中途停止游戏
6. 有复盘功能（存储棋盘状态）

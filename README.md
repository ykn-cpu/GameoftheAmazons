# 亚马逊棋(Game of the Amazons)

> 北京大学2025-2026 学年第一学期 **计算概论 A **课程大作业 

亚马逊棋（Game of the Amazons）是一种双人抽象策略棋类游戏。双方各有 4 枚棋子，每回合依次完成**移动棋子**和**射箭放置障碍**两个动作。当一方无法移动时判负。

本项目从字符界面原型出发，经历了 AI 调参和 GUI 迭代，最终呈现为一个兼具对弈能力和视觉品质的完整作品。

## ✨ 设计亮点

### 图形界面艺术设计

GUI 界面的视觉效果经过了大量反复调试，力求在 EasyX 图形库的框架下呈现出远超一般课程作业的视觉品质和用户体验。

**背景与棋盘**：主界面采用草绿色渐变填充，棋盘区域使用浅灰色渐变背景。每个棋盘格子叠加多层右下偏移阴影，模拟 3D 立体效果；棋盘交点处绘制高光圆点，增强质感。棋盘外框使用圆角矩形 + 蓝色粗线描边。

**棋子与障碍**：黑白棋子均叠加多层同心圆阴影渐变，棋子带有边框描边。鼠标悬停时，可合法选中的棋子呈现绿色光晕高亮，视觉反馈清晰。障碍物以蓝色圆角方块呈现。

**合法路径可视化**：棋子移动路径高亮为黄色渐变方块，射箭路径高亮为红色渐变方块，选中的目标位置保持黄色。所有高亮格均采用多层阴影渐变，立体感强。

**按钮与交互**：所有按钮采用圆角矩形 + 图标提示，蓝色和黄色醒目配色。状态栏根据游戏状态动态显示/隐藏存盘按钮，防止误触。主菜单支持鼠标悬停高亮。

**细节打磨**：菜单选择和执方选择配有提示音 + Windows API 弹窗；每步操作有文字引导提示；AI 走步后提示栏显示上一步走法；支持第一步悔棋（重新选子）。

### AI 算法与参数调优

AI 的核心是 **Minimax 搜索 + Alpha-Beta 剪枝 + 迭代加深**，评估函数由三个维度加权构成。关键优化包括：

- **走法排序**：搜索前用快速评估函数预排序走法，优先搜索高价值分支，大幅提升剪枝效率
- **步长压缩**：走子和射箭搜索步长压缩为 4，减少分支因子
- **超时保护**：950ms 时限，超时返回当前深度最优解，兜底逻辑防止提前认输
- **两套权值**：走法排序用 `1:3:35`（机动性:封锁:领地），Minimax 叶子节点用 `1:2:7`，分别调优

调参方法：让 AI 与基线 AI（mobility 贪心、动态贪心、混合贪心、MCTS）反复对弈，观察行棋风格——过于保守则提高攻击性权值，过于激进则提高领地权值。

## 🔧 编译与运行

| 版本 | 编译环境 |
|------|----------|
| 控制台版 | C++11 编译器，无额外依赖 |
| Botzone AI | C++11 编译器，无额外依赖 |
| GUI 两版 | Windows + Visual Studio + EasyX图形库 |

```bash
# 控制台版
g++ -o console src/console/main.cpp -std=c++11 && ./console

# Botzone AI
g++ -o bot src/bot/bot.cpp -std=c++11 -O2 && ./bot < input.txt
```

GUI 版在 Visual Studio 中创建 EasyX 项目，添加对应 `.cpp` 文件后编译即可。
